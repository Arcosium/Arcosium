## 자동화한 운영

- 한국투자파트너스 투자지원실에서 펀드 현황·IRR·AUM·투자 집계·주간보고·회사 소개자료의 반복 산출을 내부 PC Python만으로 자동화했습니다.
- `쏙똑경제`의 편당 제작 시간을 2시간→1시간→15분으로 줄인 뒤 기사·시장 데이터 수집, 대본, 이미지, TTS, 자막, 영상 합성, 예약 발행을 완전히 자동화했습니다. 약 330편을 공개했고 최고 조회수는 약 6,000회이며, 주말에는 롱폼 두 편도 자동 발행됩니다.
- Timefolio 모의투자 사이트처럼 API가 없는 환경에서도 브라우저 주문 뒤 체결·미체결 상태를 다시 확인하고, 입력값이 어긋나면 주문을 중단하는 검증 경계를 둡니다.

## 만드는 방식

- 결과 수치보다 먼저 시간분할, 위약검정, 대조군과 실패 가설을 남깁니다.
- LLM의 판단과 주문·보안·정합성 검사를 분리해 중요한 경계는 결정론적으로 통제합니다.
- 시제품에 그치지 않고 서비스, 모바일 앱, 운영 로그와 복구 경로까지 연결합니다.
- 비밀키와 사용자 데이터는 코드 저장소 밖에 두고 공개 가능한 코드와 문서만 관리합니다.

주요 도구: Python · FastAPI/Flask · TypeScript/React · Kotlin · pandas · scikit-learn · PyTorch · SQLite/PostgreSQL · Linux/systemd · Cloudflare
